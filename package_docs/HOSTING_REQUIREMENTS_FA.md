# نیازمندی‌های سخت‌افزاری و نرم‌افزاری سرور میزبان (Hosting Requirements)
# TaskYar Web 2.0 RC1

این مستند مشخصات فنی و تنظیمات موردنیاز هاست اشتراکی را جهت اجرای بهینه سامانه تسک‌یار وب ۲.۰ تشریح می‌کند.

---

## ۱. الزامات محیط PHP

| ویژگی | مقدار الزامی | وضعیت در هاست اشتراکی استاندارد |
| :--- | :--- | :--- |
| **نسخه PHP** | PHP 8.3.x یا PHP 8.4.x | در کنترل‌پنل DirectAdmin از بخش PHP Selector قابل انتخاب است |
| **memory_limit** | حداقل ۱۲۸ مگابایت (توصیه‌شده: ۲۵۶ مگابایت) | معمولاً پیش‌فرض هاست‌ها ۱۲۸ الی ۵۱۲ مگابایت است |
| **upload_max_filesize** | حداقل ۱۰ مگابایت | جهت امکان ایمپورت فایل‌های بکاپ بزرگ |
| **post_max_size** | حداقل ۱۲ مگابایت | متناسب با فایل‌های آپلودی |
| **max_execution_time** | ۳۰ الی ۶۰ ثانیه | برای اجرای نرمال درخواست‌ها و مایگریشن‌ها |

---

## ۲. ماژول‌های فعال PHP (Required Extensions)

کلیه ماژول‌های زیر برای عملکرد فریم‌ورک لاراول ۱۳ و تسک‌یار ضروری هستند و در ۹۹٪ هاست‌های اشتراکی معتبر به صورت پیش‌فرض فعال می‌باشند:
- `pdo` و `pdo_mysql`: ارتباط امن با پایگاه داده MySQL
- `mbstring`: پردازش رشته‌ها و حروف فارسی به صورت چندبایتی UTF-8
- `openssl`: رمزنگاری نشست‌ها و توکن‌ها
- `tokenizer`: پردازش سینتکس کدهای PHP
- `xml` و `dom`: کار با داده‌های ساختاریافته
- `ctype`: اعتبارسنجی نوع کاراکترها
- `json`: انکود و دیکود داده‌های کلاینت و API
- `bcmath`: محاسبات عددی دقیق
- `fileinfo`: تشخیص امن نوع فایل‌های آپلودی در بکاپ
- `curl`: ارتباط با سرویس‌ها و وب‌هوک‌ها

---

## ۳. الزامات پایگاه داده (Database)

- **نوع پایگاه داده:** MySQL 8.0 به بالا یا MariaDB 10.5 به بالا
- **موتور ذخیره‌سازی:** InnoDB (جهت پشتیبانی کامل از کلیدهای خارجی Foreign Keys و تراکنش‌های امن ACID)
- **مجموعه کاراکتر (Charset):** `utf8mb4` با کالکشن `utf8mb4_unicode_ci` (پشتیبانی کامل از زبان فارسی و ایموجی‌ها)

---

## ۴. الزامات وب‌سرور و شبکه

- **نوع وب‌سرور:** Apache 2.4+ یا LiteSpeed Enterprise (پشتیبانی از فایل `.htaccess` و ماژول `mod_rewrite`).
- **گواهی امنیتی SSL/TLS:** فعال بودن HTTPS بر روی دامنه یا ساب‌دامین (گواهی رایگان Let's Encrypt از بخش SSL Certificates در دایرکت ادمین به آسانی فعال می‌شود).
  - وجود HTTPS برای فعال‌سازی PWA، سرویس‌ورکر آفلاین و کوکی‌های امن سشن اجباری است.
- **فضای دیسک موردنیاز:** حداقل ۱۰۰ مگابایت فضای خالی بر روی هاست (شامل کدهای هسته، کتابخانه‌ها و فضای ذخیره‌سازی).
