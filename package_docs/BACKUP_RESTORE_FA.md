# راهنمای جامع پشتیبان‌گیری و بازیابی اطلاعات در تسک‌یار ۲.۰
# TaskYar Web 2.0 RC1 — Backup & Restore Guide

این مستند نحوه پشتیبان‌گیری، بازیابی و انتقال داده‌های کاربران در سامانه تسک‌یار وب ۲.۰ را در هر دو سطح (درون‌برنامه‌ای و پنل سرور) تشریح می‌کند.

---

## ۱. پشتیبان‌گیری و بازیابی درون‌برنامه‌ای (In-App JSON Backup)

تسک‌یار دارای موتور هوشمند پشتیبان‌گیری JSON است که با نسخه‌های دسکتاپ v1.1.0 و وب v1 و v2 سازگاری دارد.

### پشتیبان‌گیری (Export):
1. وارد حساب کاربری خود در تسک‌یار شوید.
2. در انتهای منوی سمت راست (سایدبار)، بر روی دکمه **«بکاپ»** (یا میانبر `Ctrl+B`) کلیک کنید.
3. فایل پشتیبان با ساختار استاندارد نسخه ۲ (`taskyar_backup_YYYY-MM-DD.json`) بلافاصله دانلود می‌شود.
4. **داده‌های مشمول پشتیبان:**
   - کلیه تسک‌ها و یادداشت‌ها
   - کلیه زیرتسک‌ها با وضعیت انجام
   - دسته‌بندی‌ها و رنگ‌ها
   - برچسب‌ها
   - الگوهای تکرار و استثناهای تکرار
   - تنظیمات یادآور پیشرفته و آلارم‌ها
   - تم انتخابی کاربر

### ارسال مستقیم به ایمیل:
- با کلیک روی گزینه **«بکاپ ایمیل»** در سایدبار، برنامه متن کارها را در کلیپ‌بورد کپی کرده، فایل JSON را دانلود و نرم‌افزار ایمیل شما را برای ارسال به آدرس دلخواه آماده می‌سازد.

### بازیابی اطلاعات (Import):
1. در سایدبار روی دکمه **«بازیابی»** کلیک کنید.
2. فایل JSON پشتیبان را انتخاب نمایید.
3. پیش‌نمایشی از تعداد تسک‌های موجود در فایل نمایش داده می‌شود؛ با تایید آن، عملیات بازیابی آغاز می‌گردد.
4. **تضمین ایمنی و تفکیک کاربر:**
   - فرآیند ایمپورت در یک تراکنش اتمیک (`DB::transaction`) انجام می‌شود. در صورت بروز هرگونه خطای فرمت یا ساختار، هیچ داده ناقصی ذخیره نشده و دیتابیس به وضعیت قبلی بازمی‌گردد.
   - شناسه‌های پایگاه داده از نو به ازای کاربر واردشده ایجاد می‌شوند تا از هرگونه تداخل با سایر کاربران جلوگیری شود.

## ۲. پشتیبان‌گیری سطح سرور از طریق DirectAdmin

جهت پشتیبان‌گیری کلی از کل سامانه (شامل تمام کاربران، فایل‌ها و تنظیمات):

### الف: بکاپ پایگاه داده از طریق phpMyAdmin
1. در DirectAdmin وارد **phpMyAdmin** شوید.
2. پایگاه داده مربوط به تسک‌یار را انتخاب کنید.
3. به تب **Export** بروید، روش **Quick** و فرمت **SQL** را انتخاب کرده و دکمه **Export** را بزنید.
4. فایل SQL دانلود شده نسخه کامل تمام اطلاعات سرور است.

### ب: بکاپ فایل‌ها از File Manager
1. در File Manager دایرکت ادمین، پوشه `/home/USERNAME/taskyar_core/` و پوشه `public_html/` را انتخاب کنید.
2. گزینه **Compress** (یا Add to Zip) را بزنید و فایل زیپ تولیدشده را دانلود نمایید.
