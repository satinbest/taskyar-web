# چک‌لیست رسمی انتشار کاندید (Release Candidate Checklist)
# TaskYar Web 2.0 RC1

این سند معیارهای کیفی و عملیاتی مورد نیاز برای تایید انتشار نسخه **TaskYar Web 2.0 RC1** را مشخص می‌کند.

- [x] اجرای کامل آزمون‌های بک‌اند: `php artisan test` (۵۳ تست، ۴۲۸ اعتبارسنجی با نتیجه **PASS** در کمتر از ۱.۹ ثانیه).
- [x] اجرای آزمون‌های واحد تقویم جلالی: `node tests/Unit/jalali.test.js` (۸ تست با نتیجه **PASS**).
- [x] اجرای آزمون‌های واحد پردازشگر زبان طبیعی: `node tests/Unit/quickParser.test.js` (۷ تست با نتیجه **PASS**).
- [x] اجرای آزمون‌های پایداری بصری و RTL: `node tests/e2e/phase5_1_stabilization_test.js` (۲۴ تست با نتیجه **PASS**).
- [x] اجرای آزمون‌های جامع رفتار کاربر در مرورگر: `node tests/e2e/phase5_e2e_test.js` (۲۵ سناریو با نتیجه **PASS**).
- [x] بیلد فرانت‌اند با Vite: `npm run build` (کامپایل در ۵۰۴ میلی‌ثانیه، حجم باندل ۳۶۸ کیلوبایت).
- [x] آزمون عدم وابستگی به CDN خارجی: `tests/Feature/AssetDependencyTest.php` (**PASS**).

## ۲. پایداری هویت بصری و رابط کاربری فارسی (Persian RTL & Visual Identity)

- [x] جهت سند `dir="rtl"` و بدون افکت چرخش آینه‌ای یا نامتعارف.
- [x] ابعاد آیکون جستجو کنترل‌شده در محدوده ۱۸ پیکسل.
- [x] قلم محلی وزیری‌متن (Vazirmatn) بدون اتصال به سرورهای خارجی.
- [x] آیکون‌های Iconsax به صورت SVG محلی در کل برنامه.
- [x] تقویم جلالی با چینش صحیح شنبه تا جمعه در بردهای هفتگی و ماهانه.
- [x] ارقام فارسی در تمام متون، برچسب‌ها و ساعت‌ها.
- [x] سازگاری کامل در ۴ تم رنگی (پیش‌فرض بنفش، اقیانوس، غروب، زمرد) و حالت شب (Dark Mode).
- [x] آزمون ابعاد واکنش‌گرا: ۳۷۵×۸۱۲ (موبایل)، ۷۶۸×۱۰۲۴ (تبلت)، ۱۲۸۰×۸۰۰ (لپ‌تاپ) و ۱۴۴۰×۹۰۰ (دسکتاپ).

## ۳. امنیت و چندکاربرگی (Multi-User Security & Isolation)

- [x] تفکیک کامل داده‌های تسک‌ها، دسته‌بندی‌ها، برچسب‌ها و آمار به ازای `user_id`.
- [x] محافظت از اندپوینت‌های ورود و ثبت‌نام با ریت‌لیمیت ۱۰ درخواست در دقیقه.
- [x] فعال‌سازی کوکی‌های امن سشن در پروداکشن (`SESSION_SECURE_COOKIE`).
- [x] پالیسی‌های مالکیت دسته‌بندی (`CategoryPolicy`) و برچسب (`TagPolicy`).
- [x] اعتبارسنجی سقف حجم پشتیبان (۱۰ مگابایت) و تعداد کارها (۵,۰۰۰ کار).
- [x] پاکسازی نشست و پایگاه داده محلی پس از خروج کاربر.

---

## ۴. همگام‌سازی آفلاین و یکپارچگی داده‌ها (Offline Sync & Data Safety)

- [x] ذخیره‌سازی داده‌های کلاینت در پایگاه داده مستقل IndexedDB به ازای هر کاربر (`TaskYarDB_{userId}`).
- [x] ثبت تغییرات در صف جهش‌ها (`pending_mutations`) در زمان قطع اتصال اینترنت.
- [x] همگام‌سازی خودکار پس از اتصال مجدد بدون حذف اطلاعات کلاینت.
- [x] ردیابی تسک‌های حذف‌شده با شناسه تامبستون (`deleted_ids`).
- [x] دیالوگ حل تعارض در صورت ویرایش همزمان یک تسک در دو دستگاه.
- [x] هشدار خروج در صورت وجود تغییرات ذخیره‌نشده روی سرور.
