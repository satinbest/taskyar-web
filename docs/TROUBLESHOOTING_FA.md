# راهنمای عیب‌یابی و حل مشکلات متداول در تسک‌یار وب (Troubleshooting Guide)

این راهنما رایج‌ترین خطاهای احتمالی هنگام نصب، راه‌اندازی و استفاده از **تسک‌یار وب ۲.۰** بر روی سرورهای هاست اشتراکی و محیط‌های محلی را به همراه راهکار قطعی آنها ارائه می‌دهد.

---

## ۱. خطای ۵۰۰ (Internal Server Error)
- **علت ۱: عدم تولید کلید برنامه (`APP_KEY`):**
  اگر فایل `.env` فاقد کلید باشد، لاراول خطای ۵۰۰ تولید می‌کند.
  *راهکار:* دستور زیر را اجرا کنید:
  ```bash
  /usr/local/php-8.4/bin/php artisan key:generate --force
  ```
- **علت ۲: مجوزهای پوشه `storage` و `bootstrap/cache`:**
  اگر وب‌سرور اجازه نوشتن لاگ یا کش را نداشته باشد خطای ۵۰۰ رخ می‌دهد.
  *راهکار:* مجوزها را روی `775` تنظیم کنید:
  ```bash
  chmod -R 775 storage bootstrap/cache
  ```

---

## ۲. خطای عدم اتصال به دیتابیس (SQLSTATE[HY000] [2002])
- **علت:** استفاده از آدرس `127.0.0.1` به جای `localhost` در تنظیمات دیتابیس در هاست دایرکت‌ادمین.
  *راهکار:* در فایل `.env` مقدار زیر را دقیقاً به شکل زیر تنظیم نمایید:
  ```env
  DB_HOST=localhost
  ```

---

## ۳. خطای محدودیت طول ایندکس (Specified key was too long; max key length is 1000 bytes)
- **علت:** سرور MariaDB به صورت پیش‌فرض از انجین قدیمی **MyISAM** برای ساخت جداول استفاده می‌کند که محدودیت ایندکس ۱۰۰۰ بایتی دارد.
  *راهکار:* تمامی مایگریشن‌های تسک‌یار وب ۲.۰ صریحاً دارای `$table->engine = 'InnoDB';` هستند. مطمئن شوید مایگریشن‌ها را به صورت تازه اجرا کرده‌اید:
  ```bash
  /usr/local/php-8.4/bin/php artisan migrate:fresh --force
  ```

---

## ۴. خطای عدم بارگذاری است‌های Vite (Unable to locate file in Vite manifest)
- **علت:** فایل `public/build/manifest.json` وجود ندارد یا است‌های فرانت‌اند در `public_html` کپی نشده‌اند.
  *راهکار:* مطمئن شوید پوشه `public/build` از بسته انتشار در روت وب (`public_html/build`) کپی شده است، یا در محیط توسعه دستور زیر را اجرا کنید:
  ```bash
  npm run build
  ```

---

## ۵. پنجره نصب PWA باز نمی‌شود یا کلیک‌ها کار نمی‌کنند
- **علت ۱: عدم استفاده از HTTPS:**
  سرویس ورکر و PWA طبق استانداردهای امنیتی وب **تنها روی دامنه امن با گواهی SSL معتبر (HTTPS)** کار می‌کنند. مطمئن شوید گواهی رایگان Let's Encrypt روی دامنه شما فعال است.
- **علت ۲: پاک نشدن کش سرویس ورکر قدیمی:**
  در مرورگر کلیدهای `Ctrl + Shift + R` (یا در مک `Cmd + Shift + R`) را بزنید یا در DevTools تب Application بخش Service Workers روی **Unregister** کلیک کنید و صفحه را مجدداً لود نمایید.

---

## ۶. خطای ۴۰۴ در روت‌های API هنگام درخواست در دایرکت‌ادمین
- **علت:** فعال نبودن یا کپی نشدن فایل `.htaccess` در ریشه `public_html`.
  *راهکار:* بررسی کنید که فایل مخفی `.htaccess` از پوشه `taskyar_core/public/.htaccess` حتماً در `public_html/.htaccess` کپی شده باشد تا درخواست‌ها به `index.php` بازنویسی (Rewrite) شوند.
